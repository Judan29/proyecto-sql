# Seguimiento de alumnos

## Descripción
Base de datos para registrar alumnos y hacer seguimiento de sus notas, materias pendientes y exámenes rendidos.

## Estructura del Repositorio
* `README.md`: Documentación general del proyecto.
* `scripts/01_tablas_base.sql`: Creación de la base de datos, tablas y carga de registros iniciales.
* `scripts/02_consultas_iniciales.sql`: Consultas básicas de validación y filtros.

## Pasos de ejecución
1. Ejecutar primero `scripts/01_tablas_base.sql` en SQL Server.
2. Ejecutar luego `scripts/02_consultas_iniciales.sql` para ver los resultados.
